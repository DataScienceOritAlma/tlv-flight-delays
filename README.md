# חיזוי עיכובי טיסות בנתב"ג (tlv-flight-delays)

פרויקט דאטה סיינס של אורית עלמה זיו-נר: חיזוי עיכובים וביטולים של טיסות בנמל התעופה בן גוריון, על נתונים שנאספים מדי יום מלוח הטיסות הפומבי של רשות שדות התעופה.

התוכנית הכוללת, הרקע והסטטוס נמצאים ב-`..\orit-ai-expert\PROJECT.md`.

## מצב הפרויקט

שלב איסוף הנתונים. האיסוף התחיל ב-12.10.2026. עדיין אין מודל.

## הנתונים

- מקור: לוח הטיסות של רשות שדות התעופה ב-data.gov.il, resource `e83f763b-b7d7-479e-b172-ae981ddc6de5`.
- המאגר מחזיק חלון מתגלגל של כמה ימים בלבד, ולכן כל הרצה שומרת תמונת מצב מלאה. ההיסטוריה נבנית מהצטברות התמונות.
- כל טיסה מופיעה בכמה תמונות מצב עוקבות, עם סטטוס שמתעדכן. הסטטוס הסופי שלה הוא זה שבתמונה האחרונה שבה היא מופיעה.

| שדה | משמעות |
|---|---|
| `CHOPER`, `CHOPERD` | קוד ושם חברת התעופה |
| `CHFLTN` | מספר הטיסה |
| `CHSTOL` | השעה המתוכננת |
| `CHPTOL` | השעה המעודכנת או בפועל |
| `CHAORD` | `A` נחיתה, `D` המראה |
| `CHLOC1`, `CHLOC1T`, `CHLOC1TH` | קוד שדה היעד או המוצא, שם העיר באנגלית ובעברית |
| `CHLOCCT`, `CHLOC1CH` | המדינה באנגלית ובעברית |
| `CHTERM` | טרמינל |
| `CHCINT`, `CHCKZN` | דלפקי ואזור הצ'ק-אין |
| `CHRMINE`, `CHRMINH` | הסטטוס באנגלית ובעברית |

## קבצים

- `collect.py` שומר תמונת מצב ל-`data/raw/flights_YYYY-MM-DD_HHMM.json` ורושם שורה ב-`data/collect.log`.
- `setup_daily_collection.bat` יוצר, בהרצה חד-פעמית בדאבל-קליק, שתי משימות מתוזמנות של Windows שמריצות את האיסוף ב-07:30 וב-19:30.

## הרצה ידנית

```
python collect.py
```
